# CodeBuddy 项目级入口

仅在用户明确给出审查范围时使用：

1. 明确范围：工作区 diff、commit 范围、单个 commit 或文件。
2. 调用项目子代理 `code-review-custom`，把审查范围和修改意图传入。
3. 子代理只读分析，不修改文件；按 P0→P3 报告有具体理由的问题。
4. 收到结果后向用户转述，不自行扩展为架构评审。

按 P0→P3 排序，只报告有具体理由、影响和修复方向的问题；只读审查，不修改文件。
