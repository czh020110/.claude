# CodeBuddy 项目级入口

当任务涉及三个以上外部技术对象，或单个对象包含复杂版本、认证、迁移细节时，调用项目子代理 `docs-research`：

- 只传外部技术问题，不传本地项目文件作为查询上下文。
- 优先使用已连接的 Context7；不可用或不足时查询官方网页。
- 结论必须区分已确认内容与不确定项，不能凭记忆补全。
- 少于三个普通接口时，主模型可直接查询官方资料。

返回 `结论 / 依据 / 建议用法 / 风险与不确定项`，依据只能来自本次实际查询。
