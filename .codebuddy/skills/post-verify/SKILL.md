# CodeBuddy 项目级入口

所有修改类任务完成后必须执行：

1. 读取 `.project-script/MEMORY.md`，优先复用匹配的验证入口。
2. 按本轮实际修改范围检查文件、路径引用、配置格式、下游影响和需求完成度。
3. 没有现成脚本时执行静态检查、解析检查、差异检查或相关测试；非 trivial 逻辑才新增可复用验证脚本。
4. 发现问题先修复再重跑验证，并明确报告命令和结果。

简单低风险修改可以使用静态检查和差异检查，不因此跳过验证；发现问题必须修复后重跑受影响检查。
